# Remote TV Display — Bluetooth Remote & Wi-Fi Recovery PWA

Static, offline-first Web Bluetooth controller for Remote TV Display Raspberry Pi appliances.

- **Live PWA:** https://dvdbrx.github.io/remote-tv-ble/
- **Android:** Open in Google Chrome and tap **Add to Home Screen** (works 100% offline once cached).
- **iOS (iPhone/iPad):** Open in the free **Bluefy** WebBLE browser app, or use **nRF Connect** with service UUID `7e4d0001-3b8a-4e2c-9a10-5c6f8e9a0b01`.
